# Clínica Levante · Nueva web

Rediseño de [clinicalevanterivas.com](https://clinicalevanterivas.com/) (centro médico privado en Rivas-Vaciamadrid).

- `web/index.html` — nueva web: promesa, oferta Primera Visita 360, Plan Familia, 23 especialidades, horario y reserva online.
- `web/propuesta.html` — propuesta comercial para la clínica, con calculadora de retorno.

Abrir cualquiera de los dos archivos en el navegador. No necesita instalación.
